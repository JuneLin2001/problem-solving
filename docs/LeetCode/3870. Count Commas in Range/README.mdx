### 解題思路

要算出總共有幾個逗號。  
然後測資很少，只有 1 `<=` n `<=` $10^5$，所以要考慮的只有三種狀況。

```js
var countCommas = function (n) {
  if (n === 1000000) return 999002; // 最大值 1000000 的狀況，會變成 1,000,000，有兩個逗號，可以先用 n - 1000 + 1 算出除他之外其他值總和，最後再加二，會變成 999002。
  if (n < 1000) return 0; // 小於 1000 的狀況，沒有逗號
  return n - 1000 + 1; // 介於 1000 到最大值的狀況，可以用 n - 1000 + 1 這個公式算出。
};
```
