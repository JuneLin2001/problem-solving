### 解題思路

要算出總共有幾個逗號。  
但測資比較大，所以不能和上一題目一樣暴力解。  
這次改用計算ㄉ。

```js
var countCommas = function (n) {
  let base = 1000; // 因為每多三個 0 才會多一個逗號，故 base 設定為 1000
  let result = 0; // 總共有幾個逗號，最少是 0 個

  while (n >= base) {
    result += n - base + 1; // 算出這輪共有幾個逗號
    base *= 1000; // 進到下一輪，base 需要乘上 1000
  }

  return result;
};
```
