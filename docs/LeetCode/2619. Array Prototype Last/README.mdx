### 解題思路

題目要求是替 Array 新增一個 `.last()` 方法，來取得陣列的最後一個元素。  
由於是在 Array.prototype 上新增，故在解題時可以使用 `this` 來取得當前陣列本身。  
直接使用 `this[this.length - 1]` 來取得最後一個元素即可。
而當陣列長度為 0 時，依照題目要求直接回傳 `-1`。

### 心得

直接操作 prototype 還滿少見的，剛好可以練習這種做法。
